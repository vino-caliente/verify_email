В docker-compose описаны 3 контейнера:
 - само приложение
 - база данных postgresql
 - mailpit для просмотра писем в рамках docker

Для запуска нужно:
 1. Создать `.env` и скопировать в него все что в `.env.example` (так как письма отправляются только в рамках контейнера то ничего секретного там нет, для бд тоже стандартные настройки, так что настраивать ничего не нужно)
 2. Запустить сборку через `docker-compose up --build`

Для того чтобы было удобнее тестировать сервис есть страница регистрации, она будет доступна после запуска по `http://localhost:8000/api/registration/`.  
Для просмотра писем `http://localhost:8025/` - ui mailpit.  
Автодокументация со списком эндпоинтов будет на `http://localhost:8000/docs`.
